# Daily Reflection Decision Tree

## Objective

To create a deterministic system where each input gives a fixed output.

## Flow

Q1: Did you complete your main goal today?

* YES:

  * Q2: Were you focused?

    * YES → Output: Great consistency. Keep following the same routine.
    * NO → Output: Try reducing distractions like mobile usage and improve focus.

* NO:

  * Q2: What was the main reason?

    * Lack of time → Output: Plan your day in advance and set priorities.
    * Distraction → Output: Eliminate distractions and create a focused environment.
    * Low motivation → Output: Break tasks into smaller steps and start with easy ones.

## Key Feature

* Same input always produces same output
* No randomness or assumptions
